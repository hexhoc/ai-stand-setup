# Комплект OpenCode для разработки на 1С

Комплект предназначен для проектов, подготовленных `dev-agent`.

## Состав

- `rules/` — самостоятельные project rules без внешнего корпуса MCP, включая read-only ревью.
- `commands/` — команда запуска YAxUnit.
- `manifest.json` — пути установки и SHA-256 управляемых файлов.

## Принципы

- Единственный MCP — `bsl-language-server` с официальным набором инструментов.
- Метаданные и ИБ обслуживаются granular skills `cc-1c-skills`; API БСП — skill `bsp`.
- `rules/` не загружается целиком: корневой `AGENTS.md` и команды выбирают только применимые правила по типу задачи.

Установка и обновление выполняются по `AI_STAND_SETUP.md`, раздел 3.4. Файлы этого каталога не копируются в целевой проект целиком: используются target paths из manifest.
