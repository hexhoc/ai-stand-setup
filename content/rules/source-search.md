# Поиск по исходникам 1С

## Маршрут

Перед семантическим поиском проверить фактический каталог MCP. В версиях с `list_workspace_folders` получить URI проекта; отсутствующую папку зарегистрировать через `register_workspace_folder` при разрешённом управлении индексом. В старых версиях проверить MCP roots. Для API-инструментов передавать `workspaceFolder`, если его требует установленная версия. В режиме ревью регистрацию выполняет основной агент до передачи задачи.

1. Известен BSL-файл — `document_symbols`, затем чтение узкого диапазона.
2. Известна позиция символа — `definition`, `find_references`, `call_hierarchy`, `hover` или `type_at_position`.
3. Известен тип платформы/глобальный член — `type_info`, `global_member_info`, `global_member_search`.
4. Нужен объект метаданных — загрузить подходящий skill (`meta-info`, `form-info`, `cf-info`, `cfe-diff`) либо выполнить точечное чтение XML.
5. Неизвестно местоположение — scoped `grep`/`glob`; большие BSL/XML целиком не читать без необходимости.

Позиции `line` и `character` нумеруются с нуля. Если BSL Language Server недоступен, использовать точечный поиск и явно сообщить ограничение.

Поиск ведётся отдельно в основной конфигурации и каждом расширении. Совпадение имени в соседнем контуре не доказывает использование нужной версии.

## Область и остановка

- Для поиска точного расположения начать с указанного файла или вероятного владельца и остановиться после достаточного точного совпадения. Оно доказывает расположение, но не уникальность.
- Для объяснения поведения проследить точку входа, вызываемые методы, релевантные метаданные и версию реализации в основной конфигурации/расширении. Не повторять полный поиск во всех каталогах без признака влияния.
- Для утверждения «используется только здесь», «не используется» или project-wide анализа проверить основную конфигурацию, все прикладные расширения и динамические точки входа. Неполное покрытие позволяет сказать только «не найдено в проверенной области».
- Указанный пользователем файл является точкой входа, но не границей, если для объяснения требуется зависимость. Явный запрет выхода за каталог — граница; зависимость за ней отмечается как непроверенная.
- Каждое решающее совпадение связывать с фактическим путём. Не определять владельца по префиксу метода или похожему имени каталога.

## Анализ влияния

Перед удалением, переименованием или изменением экспортного метода проверить `find_references`, `call_hierarchy`, строковые вызовы, подписки, команды, формы, регламентные задания и сервисы. Разделять подтверждённые зависимости и возможные динамические точки входа.

Для изменения метаданных дополнительно искать обращения в текстах запросов, RLS, СКД, отборах динамических списков, формулах, функциональных опциях и ролях. Новое имя объекта не доказывает отсутствие старой ссылки в сериализованном XML.
