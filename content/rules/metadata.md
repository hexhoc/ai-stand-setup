# Метаданные

Для операций с метаданными выбирать и загружать соответствующий skill из групп: `meta-*`, `form-*`, `role-*`, `skd-*`, `mxl-*`, `cf-*`, `cfe-*`, `subsystem-*`, `interface-*`, `xdto-*`, `template-add`, `help-add`, `support-edit`.

Перед изменением: определить основную конфигурацию/расширение, объект, состояние поддержки и область записи. После изменения: профильный validator, регистрация объекта в родительском XML и диагностика созданного BSL.

Основная конфигурация определяется отсутствием `ConfigurationExtensionPurpose`, расширение — наличием этого элемента. Для расширения проверять `ObjectBelonging`, `ExtendedConfigurationObject`, `xr:PropertyState`, `NamePrefix` и настройки сопоставления. Перехватчики сравнивать с сигнатурой и телом точной версии основной конфигурации.

## Проектирование

- До создания объекта определить владельца данных, жизненный цикл, ключ, ожидаемый объём, частые отборы, права и способ удаления или архивирования.
- Для регистра отдельно определить назначение измерений, ресурсов и реквизитов, периодичность, подчинение регистратору и индексы под фактические запросы.
- Для СКД определить источник данных, параметры, вычисляемые поля, ресурсы, варианты и настройки пользователя. Вычисление, влияющее на отбор или группировку больших данных, по возможности выполнять источником, а не постобработкой результата.
- Изменение имени, типа, периодичности, ведущего измерения, регистратора или состава движений считать изменением модели данных и проверять по всем потребителям.

## XML-инварианты

- Не редактировать `ConfigDumpInfo.xml`, не переформатировать XML целиком и не менять порядок несвязанных узлов.
- Не генерировать UUID вручную без профильного инструмента. UUID объектов, реквизитов, табличных частей и элементов должны быть уникальны во всей конфигурации; копирование UUID вместе с XML-фрагментом запрещено.
- Не добавлять стандартный реквизит `LineNumber` в описание табличной части: платформа создаёт его автоматически.
- Для группы страниц формы используется тип `PagesGroupExtInfo`; каждый элемент `Page` должен содержать `<enabled>true</enabled>`, если страница не отключена намеренно.
- Добавленный или удалённый объект должен быть согласован с родительским XML, а ссылка на объект — с точным техническим именем и UUID.
- Успешный разбор XML не заменяет профильную проверку схемы и проверку загрузки платформой.

## Поддержка и расширения

Отказ skill из-за поддержки нельзя обходить прямой правкой: использовать расширение либо после отдельного согласования загрузить skill `support-edit`. Для заимствованного объекта сохранять его идентичность и изменять только свойства, помеченные для расширения. Перехватчик `&Вместо` должен явно решать, вызывается ли исходный метод; `&ИзменениеИКонтроль` сверяется с оригинальным телом после обновления типовой конфигурации.
