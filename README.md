# ai-stand-setup

`AI_STAND_SETUP.md` — инструкция для OpenCode по подготовке XML-проекта 1С к агентской разработке. Она помогает с нуля развернуть **AI-ready XML-проект 1С**.

Она помогает агенту:

- найти или выгрузить исходники основной конфигурации и расширений;
- установить проектные skills;
- опционально подключить YAxUnit и расширение для тестов;
- настроить Git, если он ещё не настроен;
- подключить MCP BSL Language Server;
- сформировать проектный `AGENTS.md`.

`AGENTS-EXAMPLE.md` — канонический шаблон из комплекта. Инструкция читает его из исходного checkout `dev-agent`, формирует по нему проектный `AGENTS.md`.

## Комплект OpenCode для 1С

Каталог `content/` содержит комплект разработки на 1С для OpenCode V2:

- самостоятельные project rules, включая независимое read-only ревью;
- команду `/yaxunit-test`.

Единственный MCP комплекта — встроенный MCP-режим BSL Language Server. Метаданные, формы, конфигурации и ИБ обслуживаются granular skills из `cc-1c-skills`.

`AI_STAND_SETUP.md` устанавливает комплект в `.opencode/rules` и `.opencode/commands` и не перезаписывает существующие пользовательские или изменённые управляемые файлы без подтверждения.
