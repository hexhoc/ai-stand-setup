# ai-stand-setup

`AI_STAND_SETUP.md` — инструкция для OpenCode по подготовке XML-проекта 1С к агентской разработке. Она помогает с нуля развернуть **AI-ready XML-проект 1С**.

Она помогает агенту:

- найти или выгрузить исходники основной конфигурации и расширений;
- установить проектные skills;
- опционально подключить YAxUnit и расширение для тестов;
- настроить Git, если он ещё не настроен;
- подключить MCP BSL Language Server;
- сформировать проектный `AGENTS.md`.

`AGENTS-EXAMPLE.md` — единственный канонический шаблон правил проекта. При формировании `AGENTS.md` его placeholders заменяются фактическими путями и параметрами конкретного проекта, а неприменимые пункты удаляются.
